# 阅读专区

> 精选文章、报告和资料的收藏与分类管理

## 分类体系

| 分类 | 说明 | 标签 |
|------|------|------|
| 📰 行业深度 | 行业分析、趋势解读、深度报道 | `industry` |
| 📊 研究报告 | 研报、白皮书、数据分析 | `report` |
| 🛠️ 产品技术 | 产品分析、技术文档、教程 | `tech` |
| ⚡ 资讯动态 | 新闻、政策、市场快讯 | `news` |
| 💡 思考洞见 | 个人观点、方法论、思维认知 | `insight` |
| 📚 AI+教育 | AI教育赛道相关内容 | `ai-edu` |

## 如何添加内容

告诉 AI 以下任意格式即可自动收录：

- "存一下这个链接：`https://xxx`"
- "加入阅读库：标题 + 链接"
- "帮我读一下这篇文章然后存到阅读专区：`链接`"

## 数据文件

- `reading-data.json` — 所有阅读条目的结构化数据（JSON 格式）
- 本页面为索引，具体数据由知识库网页读取并渲染
