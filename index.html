🚀 部署知识库到线上

为什么需要线上部署？

  • ✅ 固定访问地址，任何设备都能打开
  • ✅ 手机/平板随时查看
  • ✅ 可分享给同事/朋友

推荐方案： GitHub Pages / Vercel / Netlify（均免费）

# GitHub Pages 部署步骤
cd knowledge-base && git init && git add .
git commit -m "初始化"
# 推送到 GitHub → Settings → Pages 启用即可
# 地址: https://你的用户名.github.io/repo名/
